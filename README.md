# EthicaLearn
**Live demo for student dashboard : https://ai-tutor-86558.web.app
Live demo for teacher dashboard : https://ai-tutor-86558.web.app/teacher.html**

EthicaLearn is an AI-powered bilingual(Tamil,English) ethical learning platform that promotes safe and meaningful education.Our motto is to create an awareness to the school students to learn AI for government school students(TamilNadu) as well as private school students to learn in a gamified manner so they can seek their interest by learning and teacher can use the dashboard to know about their own students score easily and the we the creators also see the records in our firebase DataBase.

# Overview
*EthicaLearn is a learning platform designed to provide students with a personalized AI tutor, seamless user experience, and real-time learning support. 
*It combines AI interaction, user management, and progress tracking into one unified system using teacher dashboard we can monitor the student learning track.

# Built-in AI Tutor
At the core of EthicaLearn is a smart AI tutor that: Answers student queries instantly Explains concepts in a simple and clear manner Focuses on understanding rather than memorization Provides real-time interaction This creates a personal learning assistant available 24/7.

# User Accounts & Data Persistence
EthicaLearn supports user-based learning experience: Secure user login (planned / partial) Data persistence using Firebase Stores user interactions and learning activity Personalized experience for each student Ultra-Pro UI/UX
